# BSI-Applications

Public pages for Blackwood Strategic Intelligence apps (privacy policies for the app stores), served by GitHub Pages at https://lord-blackwood.github.io/BSI-Applications/.

- `index.html`: the list of apps (carries the Google Search Console verification tag: keep it)
- `odins-gaze/privacy.html`: Odin’s Gaze privacy policy (the master copy; edit the text here)
- `assets/site.css`: Blackwood brand styles (from `_Brand/BRAND.md`); `assets/fonts`: Selawik (SIL Open Font Licence 1.1, see `Selawik-OFL.txt`)

This repository holds only these public pages. App source code is kept elsewhere.
